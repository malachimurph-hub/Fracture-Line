# Recorded voice lines (drop-in)

Put processed lines here; the game uses them automatically instead of the TTS placeholders:

    audio/voice/<faction>/<unit folder>/<event>_<n>.ogg     e.g. eu/leopold/attack_1.ogg
    audio/voice/announcer/<event>_<n>.ogg                    e.g. announcer/low_power_1.ogg

Use `python3 tools/import_voice.py <recordings...>` to trim, normalise (-16 LUFS), add the
radio filter and convert. The full list of lines is in builds/m1/VOICE_SCRIPT.md and
data/audio/voice_manifest.json (generated by tools/voice_manifest_src.py).
