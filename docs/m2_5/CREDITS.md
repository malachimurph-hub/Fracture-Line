# Credits — FRACTURE LINE (Milestone 2.5, build 0.2.5)

- **Game design, code, data, UI and text:** original work made for Malachi Murphy, built with Grok Bot.
- **Factions, units, structures, powers, map and all names:** original. This includes the United States roster names (Halberd, Lynx, Picket, Longreach, Harrier, Wraith, Thunderlance — original names, only inspired by real equipment roles), the maps Varno Crossing, Kessel Pass, Harrow Junction and Ochre Wells, and the TPLA (The Peoples Liberation Army, a working name) and its Laborer, Militia, Rocket Cell, Rattler, Scrapback, Hailstorm, Shrike, Mule and Blight units. No names, art, models, textures, audio or text from any EA or other commercial game are used, extracted or traced.
- **3D models:** original. They are built procedurally in code (`tools/gen_views.gd`, `view/props/prop_meshes.gd`) from low-poly primitives. TPLA salvage tiers are bolt-on parts on the same models.
- **Soldier models and animations:** Quaternius, "Toon Shooter Game Kit" (https://quaternius.com), **CC0 1.0** public domain — recoloured per faction (EU, TPLA, US Marines), re-equipped, decimated and baked to vertex animation (`tools/bake_infantry.gd`).
- **Model weathering** (panel lines, chipped paint, rust, grime, base dirt): original shader `view/materials/weathered.gdshader`. The panel, scratch, grime and rust masks and the stencil sheet are generated by `tools/build_textures_m2.py`. The stencils are drawn from geometric primitives, not from a font.
- **Ground decals** (tire tracks, cracks, oil stains, sand drifts, rubble): original and procedural (`tools/build_textures_m2.py`).
- **Textures from ambientCG** (https://ambientcg.com), all licensed **CC0 1.0 Universal (public domain)**. No attribution is required; it is given here anyway.

  M2 uses the 1K PBR sets: colour plus NormalGL, Roughness and Ambient Occlusion. They ship as Texture2DArrays: albedo as ETC2, normal/roughness/AO as ASTC 4x4, both with mipmaps.

- **Sound effects, UI sounds and ambience:** original. They are synthesized from scratch with NumPy DSP (`tools/gen_audio.py`, plus `tools/gen_audio_tpla.py` for the TPLA weapons, rust, salvage, tunnel and trap sounds). No samples or sound libraries are used.
- **Music:** original compositions, synthesized in `tools/gen_music.py`.
- **Voices: AI-generated** (all wording original, `tools/voice_manifest_src.py`). No real person's voice is cloned.
  - **EU and US units + announcers:** **Kokoro-82M** by hexgrad (https://huggingface.co/hexgrad/Kokoro-82M), **Apache License 2.0** (weights and voice packs), run with **kokoro-onnx** (MIT) on ONNX Runtime (MIT); phonemes by eSpeak NG (GPL-3.0, offline build tool only). EU = British voices; US (M2.5) = American voices and blends.
  - **TPLA units + announcer (M2.5): English with Middle Eastern (Arabic / Persian) accents.**
    - **Speech model: Chatterbox Multilingual** by Resemble AI (https://github.com/resemble-ai/chatterbox, https://huggingface.co/ResembleAI/chatterbox), **MIT License** (code and weights). Run with language token "ar". Chatterbox embeds Resemble's **Perth** imperceptible neural watermark in its output (MIT, https://github.com/resemble-ai/Perth); the shipped TPLA lines carry it.
    - **Voice prompts:** synthetic accented-English prompts made by `tools/accent_tts.py` with **Piper** Persian voices fa_IR **amir**, **ganji** and **reza_ibrahim** (https://huggingface.co/rhasspy/piper-voices; model cards: datasets CC0 — amir and ganji from datacula.com, reza_ibrahim from datasets by Reza Hedayatfar and Ibrahim Walk, trained by Ali Mahmoudi). Note: amir and reza_ibrahim were fine-tuned from Piper's US-English "lessac" voice, whose source dataset has its own (research-oriented) terms; these Piper voices are used only to make reference prompts, never shipped — flagged in KNOWN_ISSUES for a licence review before commercial release, then pitch- and formant-shifted into new, fictional speakers. Piper (piper-tts, GPL-3.0) is an offline tool only; only generated audio ships.
    - **Quality check:** **faster-whisper** (MIT) with OpenAI **Whisper small** weights (MIT), offline only, scores each line for intelligibility; poor takes are re-rendered (`tools/voice_qa_me.py`).
    - Evaluated and **not** used (licence or quality): Meta MMS-TTS (CC-BY-NC 4.0, non-commercial), Coqui XTTS-v2 (Coqui Public Model License, non-commercial), F5-TTS (weights CC-BY-NC), Kokoro voice blends and Piper cross-lingual English (accent too weak / too robotic). See docs/m2_5/TTS_COMPARISON.md.
  - **Processing:** `tools/import_voice.py`: trim, faction radio filter (EU handset, TPLA rough walkie-talkie, US digital tactical radio), two-pass loudness normalization (-16 LUFS), limiter. FFmpeg offline only.
  - **Your own recordings:** files in `audio/voice/` always take priority over the AI lines.
- **Tools used offline (not shipped):** FFmpeg, Python with NumPy (BSD), Pillow (HPND), PyTorch (BSD-3), kokoro-onnx, ONNX Runtime, eSpeak NG, Chatterbox, Piper and faster-whisper.
- **Font:** Godot Engine's built-in default font (bundled with the engine).
- **Engine:** Godot Engine 4.7.2. Copyright (c) 2014-present Godot Engine contributors; (c) 2007-2014 Juan Linietsky, Ariel Manzur. MIT License.
  - The full license text is shown in-game under **Credits / About**.
  - The Android build uses a size-optimized custom build of the same 4.7.2-stable source, with unused modules disabled.
