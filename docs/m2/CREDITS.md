# Credits — FRACTURE LINE (Milestone 2, build 0.2.0-m2)

- **Game design, code, data, UI and text:** original work made for Malachi Murphy, built with Grok Bot.
- **Factions, units, structures, powers, map and all names:** original. This includes the TPLA (The Peoples Liberation Army, a working name) and its Laborer, Militia, Rocket Cell, Rattler, Scrapback, Hailstorm, Shrike, Mule and Blight units. No names, art, models, textures, audio or text from any EA or other commercial game are used, extracted or traced.
- **3D models:** original. They are built procedurally in code (`tools/gen_views.gd`, `view/props/prop_meshes.gd`) from low-poly primitives. TPLA salvage tiers are bolt-on parts on the same models.
- **Model weathering** (panel lines, chipped paint, rust, grime, base dirt): original shader `view/materials/weathered.gdshader`. The panel, scratch, grime and rust masks and the stencil sheet are generated by `tools/build_textures_m2.py`. The stencils are drawn from geometric primitives, not from a font.
- **Ground decals** (tire tracks, cracks, oil stains, sand drifts, rubble): original and procedural (`tools/build_textures_m2.py`).
- **Textures from ambientCG** (https://ambientcg.com), all licensed **CC0 1.0 Universal (public domain)**. No attribution is required; it is given here anyway.

  M2 uses the 1K PBR sets: colour plus NormalGL, Roughness and Ambient Occlusion. They ship as Texture2DArrays: albedo as ETC2, normal/roughness/AO as ASTC 4x4, both with mipmaps.

  | Used as | ambientCG asset | Maps used | Changes |
  |---|---|---|---|
  | Desert sand | Ground097 | colour, normal, roughness, AO | none |
  | Dirt; macro variation map | Ground109 | colour, normal, roughness, AO, displacement | macro map: blurred displacement |
  | Dry scrub / green grass | Grass004 | colour, normal, roughness, AO | tinted in shader |
  | Rock / cliffs | Rock063 | colour, normal, roughness, AO | desaturated and warmed; 2:1 set tiled to square |
  | Asphalt roads | Asphalt033 | colour, normal, roughness, AO | none |
  | Riverbed; close-range detail layer | Gravel035 | colour, normal, roughness, AO | detail: high-pass luminance plus normal |
  | Concrete | Concrete034 | colour, normal, roughness, AO | 2:1 set tiled to square |
  | Corrugated metal (hangars, sheds) | CorrugatedSteel005 | colour | resized |
  | Rust on models | Rust004 | colour | resized to 512 |

- **Sound effects, UI sounds and ambience:** original. They are synthesized from scratch with NumPy DSP (`tools/gen_audio.py`, plus `tools/gen_audio_tpla.py` for the TPLA weapons, rust, salvage, tunnel and trap sounds). No samples or sound libraries are used.
- **Music:** original compositions, synthesized in `tools/gen_music.py`.
- **Voices: AI-generated.** All 334 unit and announcer lines in the EU and TPLA voice scripts are generated offline. Every line's wording is original (`tools/voice_manifest_src.py`).
  - **Speech model:** **Kokoro-82M** by hexgrad (https://huggingface.co/hexgrad/Kokoro-82M), **Apache License 2.0**. This covers the model weights and the voice packs (`kokoro-v1.0.onnx`, `voices-v1.0.bin`).
  - **Runtime:** **kokoro-onnx** 0.6.1 (https://github.com/thewh1teagle/kokoro-onnx), **MIT License**, on ONNX Runtime (MIT).
  - **Phonemizer:** **eSpeak NG** (https://github.com/espeak-ng/espeak-ng), GPL-3.0. It is only a build tool: only the generated audio ships, not the program.
  - **Voices:** built-in Kokoro voices and blends of them. EU lines use British English voices; TPLA lines use American English voices. No real person's voice is cloned or imitated, and no ethnic accent is imitated.
  - **Processing:** each line goes through `tools/import_voice.py`: trim, then a faction radio filter, then two-pass loudness normalization, then a limiter. FFmpeg (LGPL/GPL) is used offline and does not ship.
  - **Your own recordings:** files in `audio/voice/` always take priority over the AI lines. The labelled eSpeak NG placeholders remain as a last fallback.
- **Tools used offline (not shipped):** FFmpeg, Python with NumPy (BSD), Pillow (HPND) for texture building, kokoro-onnx, ONNX Runtime and eSpeak NG.
- **Font:** Godot Engine's built-in default font (bundled with the engine).
- **Engine:** Godot Engine 4.7.2. Copyright (c) 2014-present Godot Engine contributors; (c) 2007-2014 Juan Linietsky, Ariel Manzur. MIT License.
  - The full license text is shown in-game under **Credits / About**.
  - The Android build uses a size-optimized custom build of the same 4.7.2-stable source, with unused modules disabled.
- **Inspiration:** the classic base-building RTS genre, especially Generals/Zero Hour-style play and look.
