# M1 stubs

Every stub below is marked **[STUB]** in the game and listed in KNOWN_ISSUES.md. None of them pretends to work.

| Feature | Where it appears | What happens in M1 |
|---|---|---|
| Superweapons option | Skirmish setup toggle, labelled "Superweapons [STUB]" | The setting is saved with the match, but M1 has no superweapon structures, so it has no effect. |
| Grid Blackout (rank-4 General's power) | General's tray, button tagged [STUB] | You cannot buy or fire it. Tapping it shows "[STUB] Not available in M1". The sim also rejects it (REASON_STUB). |
| Wolfhound transport | Wolfhound unit info, "[STUB]" tag | The Wolfhound is a working scout and combat car, but it cannot carry infantry. |
| Other factions | Lobby faction dropdown | They are greyed out as "coming later". Only EU Alliance can be chosen. |

These are **not implemented and not shown** in M1, so they are not stubs: supply crates, aircraft, naval units, audio and music, multiplayer, campaign and tutorial (deferred, see GDD §19.3).
