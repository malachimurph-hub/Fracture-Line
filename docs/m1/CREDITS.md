# Credits — FRACTURE LINE (Milestone 1)

- **Game design, code, data, UI and text:** original work made for Malachi Murphy, built with Grok Bot.
- **3D models:** made procedurally in code from engine primitives (boxes, cylinders, spheres). There are no imported art assets.
- **Terrain, map (Varno Crossing), factions and unit names:** original.
- **Audio:** none in M1.
- **Font:** Godot Engine's built-in default font (bundled with the engine, same MIT/OFL terms as the engine distribution).
- **Engine:** Godot Engine 4.7.2. Copyright (c) 2014-present Godot Engine contributors; (c) 2007-2014 Juan Linietsky, Ariel Manzur. MIT License.
  The full license text is shown in-game under **Credits / About**.
  The Android build uses a size-optimized custom build of the same 4.7.2-stable source; unused modules are disabled, but the code is otherwise unmodified.
- **Inspiration:** the classic base-building RTS genre, especially Generals/Zero Hour-style play.
  No names, art, audio, text or other assets from any EA or other commercial game are used.
